¿Qué hace este sistema?

La plataforma analiza automáticamente el comportamiento de perros utilizando Machine Learning. El modelo identifica patrones y clasifica a las mascotas como tranquilas, nerviosas o agresivas dependiendo de los datos ingresados.

¿Por qué se creó?

El objetivo es ayudar a las guarderías caninas a prevenir conflictos entre mascotas, mejorar la convivencia y facilitar las decisiones del personal encargado mediante predicciones inteligentes.

Uso de IA

El proyecto utiliza modelos de inteligencia artificial entrenados con datasets en formato CSV. Gracias a esto, el sistema aprende patrones reales y puede realizar análisis automáticos con porcentajes de confianza.

Beneficios

Permite optimizar evaluaciones, ahorrar tiempo, reducir riesgos y brindar una experiencia más segura tanto para las mascotas como para los encargados de la guardería.
